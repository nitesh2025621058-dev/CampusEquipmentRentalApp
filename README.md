# 캠퍼스 기자재 대여 앱

학번 또는 교직원 ID로 로그인하여 기자재를 조회하고 대여를 신청하는 Android 앱입니다.

## week7-room: 회원가입 추가 처리 완료

`week6-room`의 Room Entity·DAO 구조를 기반으로 회원가입과 DB 기반 로그인을 추가했습니다.

| 구분 | week6-room | week7-room |
| --- | --- | --- |
| 회원가입 | 회원가입 화면 없음 | 로그인 화면의 회원가입 링크, `fragment_join.xml`, `ui/user/JoinFragment.kt` 및 내비게이션 추가 |
| 회원 저장 | `UserEntity`와 `UserDao` 정의 | 사용자 ID·이름·학과·역할을 입력하여 `users` 테이블에 저장 |
| 입력 검증 | 회원가입 검증 없음 | 필수 입력 검사 및 트랜잭션을 통한 중복 ID 가입 방지 |
| 로그인 | `UserRepository`의 샘플 목록 조회 | Room의 `users` 테이블에서 사용자 ID로 조회하여 로그인 |
| 기본 회원 | 코드에 샘플 회원 보관 | DB를 열 때 샘플 회원 중 누락된 사용자만 추가 |
| DB 업그레이드 | 버전 2에 사용자·기자재 테이블 정의 | 버전 1 → 2 마이그레이션을 추가하여 기존 대여 데이터 유지 |

회원가입을 완료하면 로그인 화면으로 돌아가 가입한 ID가 자동 입력됩니다. 로그인은 기존 방식과 동일하게 사용자 ID만 사용합니다.

기존 `User` 모델과 `UserRepository`는 유지하며, `UserRepository`의 조회 코드는 현재 모델의 `userId` 필드에 맞췄습니다.
